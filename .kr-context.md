# kepler-releases — Solution Context

## Solution Overview
PUBLIC installer repo for KeplerCrew Enterprise edition (self-hosted). Hosts the one-liner
install scripts on GitHub Pages at **https://get.keplercrew.com**. Bundles themselves are NOT
here — they live on Keygen Dist (license-gated; product AIDC `distributionStrategy=LICENSED`).
Source repos stay private; this repo is public by design (installers only, privacy-gated).

## Features
- `install.ps1` — Windows one-liner (`irm https://get.keplercrew.com/install.ps1 | iex`).
  PS 5.1-safe, no param(). Flow: license key (env `KEPLER_LICENSE_KEY` or hidden Read-Host;
  fails fast when stdin non-interactive) → Keygen validate → resolve latest/pinned PUBLISHED
  release → singular artifact GET by convention name `KeplerCrew-win32-x64-<ver>.zip`
  (license auth CANNOT list artifacts) with manual 303 handling (.NET throws WebException on
  the 303 when auto-redirect off — recovered from `$_.Exception.Response`; do not "fix") →
  sha256 verify vs artifact metadata → extract `%LOCALAPPDATA%\Programs\KeplerCrew` →
  key stored `licenses\customer.key` user-only ACL → launch run.ps1.
  Env: KEPLER_VERSION, KEPLER_DRY_RUN=1, KEPLER_INSTALL_DIR, KEPLER_NO_LAUNCH=1.
- `install.sh` — POSIX stub: validates key, "coming soon" until mac/linux bundles publish.
- Release-side publishing: kepler-keygen-admin CLI (`release`/`artifact`/`entitlement`
  groups) — see /kepler-client-localversion-releaser PHASE 7.

## Gotchas
- **GitHub Pages legacy builder ran Jekyll and FAILED the build** ("Page build failed", no
  detail) → fixed with `.nojekyll` (2026-08-06). If builds wedge on "building"/"errored":
  force one with `POST /repos/.../pages/builds`.
- Custom-domain TLS cert issues only AFTER the first successful build; re-trigger with
  `PUT /repos/.../pages -f cname=get.keplercrew.com` (same trick as codecrew). Changing
  cname via API can commit CNAME churn to main — `git pull --rebase` before pushing.
- Commit identity: repo git config pins `aichargelabs <releases@aichargelabs.com>` — NEVER
  commit as KR (public repo, anonymous-commits rule).
- Downloads gate proof (live-verified 2026-08-06): no-auth → 404, bogus key → 401, valid
  license → 303 signed URL (~15 min TTL), revoked key → 401 immediately.
- Entitlement `CLIENT_LOCAL` `aad1554d-8ed0-45be-b4a4-bf8e16211b03` attached to the 7d trial
  policy; constrain each release with `release constrain <rid> --entitlements aad1554d-...`.
